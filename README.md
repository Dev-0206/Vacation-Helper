Vacation Helper:

Vacation Helper is a Flask web app that helps users compare trip destinations based on budget and trip length.

Features:
- Enter origin airport, budget, and number of nights
- View top trip options
- Click a destination for more details
- View current weather for a destination using OpenWeather

How to Run:
1. Install Flask and requests
2. Add your OpenWeather API key in `app.py`
3. Run `python app.py`

Files:
- `app.py`
- `destinations.csv`
- `templates/index.html`
- `templates/results.html`
- `templates/destination.html`
