# Vacation Helper

A Flask trip planner. Enter a budget and trip length, and it ranks US destinations by what fits, showing the math (sample flight + hotel x nights) behind each one.

## Two versions
- **Class version (original submission):** preserved at the git tag `class-submission`.
- **v2 redesign (current `main`):** built after the class ended. Scenic per-destination backgrounds, live "how many fit" feedback, filters and sorting, side-by-side compare, a nights slider that recalculates cost, input validation, and accessibility work. See `ai.txt` for how AI was used.

## What is real and what is not
- **Estimated:** flight and hotel prices come from `destinations.csv`. They are sample numbers, not live quotes.
- **Not used:** the origin airport does not change flight prices. It only removes that city from the list.
- **Live:** current weather from OpenWeatherMap (needs a free API key; the app works without it and says so).
- **Not included:** taxes, food, local transport.

## Run it
```
pip install -r requirements.txt
cp .env.example .env      # add OPENWEATHER_API_KEY (optional)
python app.py
```
Open http://127.0.0.1:5000. Set `FLASK_DEBUG=1` for debug mode.

## Scenes
Backgrounds are original SVG illustrations generated by `tools/make_scenes.py` (`python tools/make_scenes.py` regenerates `static/scenes/`).

## Known limits
Static price list, no real flight data, US cities only, no accounts or saved trips, runs locally.
